# 💛 موعدنا — محمود وشروق 💍

موقع ويب تفاعلي ورومانسي متكامل باللغة العربية، مصمم بأسلوب أنيق وخفيف ومرح خصيصًا ليشارك محمود خطيبته شروق تفاصيل طلعتهما معًا، بدايةً من قبول الدعوة وحتى إرسال تفاصيل الموعد عبر واتساب.

---

## 🌟 مميزات الموقع

1. **شاشة الدعوة الذكية وزر «لا» الهارب**:
   - زر «نعم 😍» ثابت ومبهج ويطلق احتفال القلوب والكونفيتي.
   - زر «لا 🙈» يهرب بذكاء وسلاسة عند اقتراب الفأرة (على الكمبيوتر) أو محاولة لمسه (على الهاتف)، مع عبارات فلسطينية لطيفة تتغير بالتتابع دون إمكانية الضغط عليه أو إرباك التنسيق.

2. **اختيار المدينة والمحلات بدقة**:
   - مدينتا **دير البلح** و **خان يونس**.
   - فلترة ذكية لمحلات الأكل والتحلاية المخصصة لكل مدينة تلقائيًا.
   - إعادة تعيين اختيارات الأكل والتحلاية عند تغيير المدينة لتفادي التضارب.

3. **اختيار اليوم والساعة بدقة ومرونة**:
   - عرض الأيام السبعة القادمة ديناميكيًا حسب التاريخ الحالي دون تواريخ قديمة.
   - خيار «بفضّل يوم ثاني 📆» يتيح اختيار أي تاريخ مستقبلي مع منع التواريخ الماضية.
   - الساعات تبدأ من ١٢:٠٠ ظهرًا ومقسمة بانتظام حتى المساء.
   - خيار «بفضّل موعد مخصص ⏱️» يتيح لشروق اختيار أي ساعة ودقيقة تناسبها.

4. **إضافات ولمسات وملاحظة خاصة**:
   - خيارات متعددة: قهوة سوا ☕، تمشاية 🚶، نتصوّر صور حلوة 📸، مفاجأة من محمود 🎁.
   - حقل اختياري لكتابة أي ملاحظة أو طلب خاص بخاطر شروق.

5. **بطاقة الملخص الأنيقة**:
   - عرض كافة الاختيارات بأسلوب بطاقة رومانسية مرتبة.
   - زر إرسال مباشر إلى واتساب محمود برسالة جاهزة ومنسقة.
   - زر نسخ تفاصيل الموعد بنقرة واحدة مع إشعار تأكيد.
   - زر تعديل الاختيارات وزر بدء الاختيار من جديد.

6. **حفظ المسودة محليًا (LocalStorage)**:
   - يتم حفظ اختيارات شروق تلقائيًا، فإذا تم تحديث الصفحة تعود إلى المكان ذاته، مع إمكانية مسحها وبدء من جديد.

## ⚙️ كيفية تعديل الإعدادات (`config.js`)

ملف `config.js` منظم ومعلّق باللغة العربية بالكامل:

### رقم واتساب محمود:
تم ضبط رقمك تلقائيًا في ملف [config.js](file:///e:/Appointment/config.js):
```javascript
whatsappNumber: '972594371086',
```
عندما تضغط شروق على زر «ابعث اختياراتي لمحمود على واتساب 💌»، سيفتح تطبيق واتساب محادثة معك مباشرة بالرسالة المنسقة لتضغط إرسال.

## 🚀 كيفية تشغيل الموقع على جهازك

يمكنك تشغيل الموقع بإحدى الطرق التالية:

### الطريقة الأولى (الأسهل بنقرة واحدة):
- انقر نقرًا مزدوجًا على ملف `index.html` ليفتح مباشرة في أي متصفح (Chrome, Edge, Safari, Firefox).

### الطريقة الثانية (عبر خادم محلي):
باستخدام سطر الأوامر في مجلد المشروع:
```bash
# باستخدام بايثون
python -m http.server 8080

# أو باستخدام Node.js
npx serve .
```
ثم افتح الرابط: `http://localhost:8080`

## 🌐 كيفية نشر الموقع والحصول على رابط لإرساله لشروق

لكي تتمكن شروق من فتح الموقع على هاتفها من أي مكان، يمكنك نشره مجانًا خلال دقيقتين بإحدى الطرق التالية:

### 1. عبر GitHub Pages (موصى بها ومجانية 100%):
1. أنشئ مستودعًا جديدًا (New Repository) على حسابك في GitHub باسم مثل `our-date`.
2. ارفع ملفات المشروع (`index.html`, `style.css`, `script.js`, `config.js`).
3. اذهب إلى **Settings** > **Pages** > اختر فرع **main** / root واضغط **Save**.
4. ستحصل على رابط رسمي مثل:
   `https://YOUR_USERNAME.github.io/our-date/`

### 2. عبر Vercel أو Netlify (سحب وإفلات Drop):
1. ادخل إلى [Netlify Drop](https://app.netlify.com/drop).
2. اسحب مجلد المشروع بالكامل وأفلته في الصفحة.
3. ستحصل فورًا على رابط مباشر وجميل يمكنك إرساله لشروق على واتساب! 💛
